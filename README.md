# SR Ludo starter

A simple PHP free-play landing page starter for the `Srk-ludu` GitHub repository.

## Files
- `index.php` — homepage and a small session-based player-name greeting.
- `style.css` — responsive styling.

## Run
Upload both files to the root of a PHP-enabled web host. Open the domain to view the page.

## Important
This is only a free-play starter/landing page. It does not contain real-money games, deposits, withdrawals, payment processing, or a production multiplayer game. Add any such features only after legal review and authorized provider approval.
